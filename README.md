# FPVmonitor

FPV-монітор на **ESP32-S3 Super Mini** з вбудованим приймачем **RX5808**, круглим дисплеєм
**GC9A01 1.28" 240x240** для інтерфейсу та будь-яким екраном з **CVBS**-входом для відео.

Можна дивитися відео з вбудованого RX5808 або з зовнішнього приймача на гребінці
(RX5808-сумісний модуль, як у Skyzone / Fatshark module bay). Джерело вибирається фізичним
двопозиційним перемикачем, прошивка сама визначає, який приймач активний.

## Можливості

- **Monitor** — ручний вибір сітки, каналу або точної частоти (5300–5999 МГц), RSSI-шкала по колу.
- **Scan** — один прохід діапазону, результат: спектр по колу та список 5 найсильніших
  каналів з RSSI; стрілками відео перемикається між ними, OK — пересканувати.
- **Detector** — безперервний пошук по вибраних сітках окремим модулем-сканером: список
  найсильніших каналів, шкала частот по колу з підписами, бузер на новий сигнал.
  Стрілками відео перемикається між знайденими каналами без зупинки пошуку.
- **Settings** — поріг детектора, сітки для пошуку, діапазон скану, бузер,
  калібровка RSSI окремо для вбудованого і зовнішнього приймача.
- Сітки **A, B, E, F, R, L** (48 каналів).
- Збереження частоти, режиму та калібровки в NVS.
- Керування трьома кнопками: UP / OK / DOWN.

## Залізо

| Компонент | Призначення |
|---|---|
| ESP32-S3 Super Mini | контролер |
| RX5808 (SPI-режим) | вбудований приймач 5.8 ГГц |
| RX5808-сумісний модуль на гребінці | зовнішній приймач (опційно) |
| GC9A01 1.28" 240x240 SPI | інтерфейс |
| Екран з CVBS-входом | відео |
| DPDT перемикач на 2 положення | вибір джерела відео + датчик положення |
| 3 кнопки | керування |
| Бузер + NPN транзистор | сигналізація |

Повна схема, пінмап і опис керування: **[docs/wiring.md](docs/wiring.md)**.

### Коротко про піни

| GPIO | | GPIO | |
|---|---|---|---|
| 1 | RSSI INT | 9 | TFT DC |
| 2 | RSSI EXT | 10 | TFT CS |
| 3 / 4 / 5 | UP / OK / DOWN | 11 / 12 | TFT MOSI / SCK |
| 6 / 7 | RX DATA / CLK (спільні) | 43 | бузер |
| 8 / 13 | LE INT / LE EXT | 44 | датчик перемикача |

## Збірка та прошивка

Потрібен [PlatformIO](https://platformio.org/).

```sh
pio run                 # збірка
pio run -t upload       # прошивка через USB
pio device monitor      # лог (115200)
```

Піни, діапазони та таймінги налаштовуються в [src/config.h](src/config.h).

## Керування

| Кнопка | Дія |
|---|---|
| Довгий OK | головне меню з будь-якого режиму |
| OK | вибір / наступне поле |
| UP / DOWN | змінити значення; утримання — автоповтор з прискоренням |

Після першого запуску варто відкалібрувати RSSI: *Settings → Cal min* при вимкненому VTX,
*Cal max* — з увімкненим VTX поруч (для кожного положення перемикача окремо).

## Структура

```
src/
  config.h          піни та константи
  rx5808.*          драйвер RX5808 (SPI bit-bang, RSSI)
  receivers.*       вбудований + зовнішній приймач, датчик перемикача
  channels.*        таблиці сіток
  buttons.*, buzzer.*, settings.*, display.*
  ui/               екрани: menu, monitor, scan, detector, settings
docs/wiring.md      схема підключення
```

## Обмеження

- RX5808 налаштовується з кроком 2 МГц.
- Модулі з власним протоколом (RapidFIRE, Steadyview тощо) не керуються командами RX5808 —
  вони працюють автономно, монітор лише перемикає на них відео.
- Підписи на дисплеї англійською (вбудовані шрифти без кирилиці).
