# FPV-монітор — підключення

ESP32-S3 Super Mini + RX5808 (вбудований) + RX5808-сумісний модуль на гребінці (зовнішній)
+ GC9A01 1.28" 240x240 (інтерфейс) + екран з CVBS-входом (відео).

Всі піни задаються в [src/config.h](../src/config.h). Перед паянням звірте з пінаутом своєї плати.

## Пінмап ESP32-S3

| GPIO | Куди | Примітка |
|---|---|---|
| 1  | RSSI вбудованого RX5808 | ADC1 |
| 2  | RSSI зовнішнього модуля | ADC1, якщо RSSI > 3.1 В — дільник |
| 3  | Кнопка UP   | на GND, внутрішній pull-up |
| 4  | Кнопка OK   | на GND |
| 5  | Кнопка DOWN | на GND |
| 6  | DATA (RX5808 CH1) | спільна для обох модулів |
| 7  | CLK  (RX5808 CH3) | спільна для обох модулів |
| 8  | LE   (RX5808 CH2) вбудованого | |
| 13 | LE   (CH2) зовнішнього | |
| 9  | GC9A01 DC  | |
| 10 | GC9A01 CS  | |
| 11 | GC9A01 SDA (MOSI) | |
| 12 | GC9A01 SCL (SCK)  | |
| 14 | GC9A01 RES | апаратний reset |
| 15 | GC9A01 BLK | підсвітка, PWM (яскравість) |
| 43 | Бузер (база NPN через 1 кОм) | при завантаженні може коротко пискнути (UART0 TX) |
| 44 | Датчик положення перемикача | див. нижче |

GC9A01: `RES` — на GPIO14, `BLK` — на GPIO15 (PWM, яскравість `TFT_BL_DEFAULT` у `config.h`). Якщо струм підсвітки модуля великий (>20 мА), постав NPN/MOSFET, як для бузера.

## RX5808

- Живлення 5 В, земля спільна з ESP32.
- Модуль має бути в **SPI-режимі**. На частині старих модулів SPI вмикається модифікацією
  (відпаяти резистор на лінії SPI_EN) — перевірте свою ревізію.
- `CH1 = DATA`, `CH2 = LE (SEL)`, `CH3 = CLK`.
- Лінії модуля 3.3 В-сумісні, рівні ESP32 підходять напряму.

## Зовнішній приймач на гребінці

Гребінка: `5V, GND, VIDEO, RSSI, CH1(DATA), CH2(LE), CH3(CLK)`.
Прошивка керує ним тими ж командами, що й RX5808 (частота, RSSI). Модулі з власним
протоколом (RapidFIRE, Steadyview тощо) так не керуються — вони працюватимуть автономно
зі своїми кнопками, а монітор лише перемкне відео та покаже `EXT`.

## Перемикач відео (DPDT, 2 положення)

```
              полюс A (відео)                     полюс B (датчик)
VIDEO_INT ──o                              (вільно) o
             \__ COM ──► CVBS-вхід екрану            \__ COM ──► GPIO44 (pull-up)
VIDEO_EXT ──o                               GND ──── o
```

- Положення **INT**: на екран іде відео з вбудованого RX5808, GPIO44 = HIGH.
- Положення **EXT**: на екран іде відео з гребінки, GPIO44 замкнений на GND.
- Прошивка бачить зміну, пищить, ставить поточну частоту на вибраний модуль і показує `INT`/`EXT`.
- Земля відео спільна; провід відео — коротко або екранований.

## Керування

| Кнопка | Дія |
|---|---|
| Довгий OK | у головне меню з будь-якого режиму |
| UP / DOWN | змінити значення / пункт; утримання — автоповтор з прискоренням |
| OK | вибір / наступне поле |

### Режими

- **Monitor** — OK перемикає поле *Сітка → Канал → Частота*; UP/DOWN змінюють його.
  Частота вводиться з кроком 1 МГц (5300–5999), RX5808 реально налаштовується з кроком 2 МГц.
- **Scan** — безперервний прохід діапазону кроком 5 МГц, спектр і до 5 найсильніших піків.
  UP/DOWN — вибір піку, OK — налаштуватися на нього і перейти в Monitor.
- **Detector** — постійний пошук по каналах вибраних сіток (Settings → Band X).
  При сигналі вище порогу (шумова підлога + Thresh) — бузер і червоний екран, приймач
  залишається на каналі (відео видно на CVBS-екрані), пікання частішає із силою сигналу.
  UP — пропустити канал на 60 с, DOWN — заглушити до виходу з режиму, OK — перейти в Monitor.
- **Settings** — поріг детектора, сітки для детектора, діапазон скану, бузер,
  калібровка RSSI (окремо для INT і EXT — для того, що вибрано перемикачем):
  `Cal min` — VTX вимкнений, `Cal max` — VTX увімкнений поруч на поточній частоті.
